# Apps Enclave: Client Applications

> Direktori aplikasi pengguna akhir (Frontend Web, Admin Dashboard, Mobile).
> Setiap aplikasi di dalam folder ini mengonsumsi API melalui `contracts/api/` dan tipe data di `packages/shared-types/`.

---

## Directories
- `web/`: Aplikasi web utama (React, Next.js, Astro, Vue, atau Svelte).
